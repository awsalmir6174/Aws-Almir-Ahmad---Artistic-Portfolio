# Art and choral portfolio

A dated archive of sixteen artworks, six choral recordings, theatre and wrestling, 2013 to 2026.

## Publish on GitHub Pages

1. Create a new public repository. Name it `portfolio` (the site will live at
   `https://YOURNAME.github.io/portfolio/`), or name it `YOURNAME.github.io`
   to have it live at the root.
2. Upload every file and folder here, keeping the structure intact:
   `index.html`, `style.css`, `viewer.js`, `works/`, `thumbs/`.
3. In the repository, open Settings, then Pages.
4. Under Build and deployment, set Source to "Deploy from a branch",
   branch `main`, folder `/ (root)`. Save.
5. Wait a minute, then reload the Pages settings screen for the live URL.

## Notes

- `thumbs/` holds the images the page loads first. `works/` holds the full
  resolution versions, opened when a viewer selects an image.
- The page carries a `noindex` tag, so search engines will not list it.
  Anyone with the link can still open it. Remove the tag in `index.html`
  if you want it indexed.
- Verifier contact details are deliberately not on the page.
